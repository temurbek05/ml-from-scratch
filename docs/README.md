# Derivations

Three files live here, each with the full math:

- `01-linear-regression.md`
- `02-logistic-regression.md`
- `03-pca.md`

A good derivation: states the problem, defines every symbol and its shape, derives step by step, and ends with a short notes section. The derivations are written by the AI assistant (Claude) at the repository owner's direction, and each one is checked numerically against the code (tests, finite differences, comparison with the closed form).
